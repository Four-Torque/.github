# 🎓 EduOps — 학원 운영 관리 시스템

> 학생·강사·수업·출결·성적·급여·비품·결재까지, 학원 운영 업무를 한 곳에서 처리하는 웹 서비스입니다.

### 🔗 서비스 바로가기 → **https://eduops.duckdns.org**

별도 설치 없이 위 링크에 접속해 바로 사용할 수 있습니다.
이 문서는 **실제 사용자가 EduOps를 어떻게 쓰는지** 역할별로 안내합니다.

---

## 📖 EduOps는 누구를 위한 서비스인가요?

학원에서 일하는 세 종류의 사용자가, 각자 **자기 업무에 맞는 화면**만 보면서 일합니다.

| 역할 | 한 줄 소개 | 로그인 후 첫 화면 |
|---|---|---|
| 👑 **원장** | 학원 전체를 조망하고, 매출을 확인하고, 결재를 승인합니다 | 학원 현황 대시보드 |
| 🗂️ **관리자** | 학생·강사·수업·수강료 등 운영 실무를 담당합니다 | 학원 기본 정보 |
| 👩‍🏫 **강사** | 본인 수업의 출결·성적·자료를 관리합니다 | 수업 시간표 |

> 로그인하면 **본인 역할에 맞는 화면으로 자동 이동**하며, 권한이 없는 페이지에는 접근할 수 없습니다.

---

## 🚪 시작하기 — 계정 만들고 로그인하기(강사, 관리자)

### 1. 회원가입

`https://eduops.duckdns.org` 접속 → **회원가입** 클릭 → 아래 정보를 입력합니다. <br>

- **이메일** — 로그인 아이디로 사용됩니다
- **이름**
- **전화번호** — `010-1234-5678` 형식
- **비밀번호** — 8자 이상, **대문자·소문자·숫자·특수문자를 모두 포함**해야 합니다
- 약관 동의

### 2. 이메일 인증

가입 후 입력한 이메일로 **인증 메일**이 발송됩니다.
메일의 링크를 클릭하면 가입이 완료됩니다. (인증 링크는 발급 후 15분간 유효합니다)

### 3. 로그인

이메일과 비밀번호로 로그인합니다.
'이메일 기억하기'를 체크하면 다음 접속 시 이메일이 자동 입력됩니다.

> 💡 **비밀번호를 잊었다면?** 로그인 화면의 **비밀번호 찾기** → 이메일 입력 → 메일로 온 링크에서 새 비밀번호를 설정하면 됩니다.

## 👑 원장(DIRECTOR) 사용 가이드

원장은 학원 전체를 관리하는 최고 권한 계정입니다. 로그인하면 **학원 현황 대시보드**로 들어갑니다.
<br>

### 🔑 원장 계정은 어떻게 발급되나요?

원장 계정은 **일반 회원가입으로 만들 수 없습니다.**
학원 최초 도입 시, **운영자가 데이터베이스에 직접 원장 계정을 생성(발급)** 합니다.
<br>
```
 운영자가 DB에 원장 계정 등록  →  발급받은 이메일/비밀번호로 로그인  →  학원 운영 시작
```
- 원장은 이렇게 발급받은 계정으로 **바로 로그인**하면 됩니다. (이메일 인증 절차 없음)
- 이후 강사·관리자는 회원가입으로 합류하며, 원장이 **사용자 관리**에서 이들을 확인·관리합니다.
- 최초 로그인 후 **비밀번호 찾기**를 통해 비밀번호를 본인만 아는 값으로 변경하는 것을 권장합니다.

> ℹ️ 즉, **원장 = 최초 발급 계정**, **강사/관리자 = 회원가입으로 합류**하는 구조입니다.
<br>

### 이런 일을 할 수 있어요

**📊 대시보드 — 학원 현황**
학원의 핵심 지표를 한눈에 확인합니다.

**👥 사용자 관리 — 사용자 목록**
강사·관리자 등 구성원 목록을 보고, 계정 상태(활성/비활성)와 재직 상태를 관리합니다.
사용자 계정의 역할을 부여합니다.
<br>

**💰 매출 관리**
- **매출 현황** — 전체 매출을 조회
- **월간 매출 현황** / **연간 매출 현황** — 기간별 매출 추이 확인
<br>

**📦 자재/결재 관리**
- **자재 목록** — 학원 비품·재고 현황
- **결재 관리** — 관리자가 올린 **비품 신청을 승인 또는 반려**합니다 (반려 시 사유 입력)
<br>

**💬 쪽지** — 구성원과 받은/보낸 쪽지를 주고받습니다.
<br>

> 원장은 위 기능 외에도 관리자 화면 일부(학원 정보, 직원 근태, 결제 내역)를 함께 볼 수 있습니다.
<br>

### 예시 흐름: 비품 신청 결재하기
```
결재 관리 → 대기 중인 신청 확인 → 내용 검토 → 승인 (또는 반려 사유 작성 후 반려)
```

## 🗂️ 관리자(MANAGER) 사용 가이드

관리자는 학원 운영 실무를 담당합니다. 로그인하면 **학원 기본 정보** 화면으로 들어갑니다.
<br>
### 이런 일을 할 수 있어요
**🏫 학원 정보**
- **학원 기본 정보** — 학원 정보 조회/관리
- **원생 관리** — 학생 등록, 상태 관리(재원/정학/퇴학), 검색
- **강좌 관리** — 수업(강좌) 개설 및 관리
- **스케줄 관리** — 수업 시간표(요일·시간·강의실) 편성
- **강사 관리** — 강사 정보 및 급여 관리
<br>

**🕘 근태 관리 — 직원 근태**
직원의 출퇴근 근태를 관리합니다.
<br>

**📦 자재 관리**
- **자재 물품 신청** — 필요한 비품을 신청합니다 (→ 원장이 결재)
- **구매처 관리** — 거래처(공급업체) 정보 관리
<br>

**💳 결제 목록 — 원생 결제 내역**
학생별 수강료 청구·납부 현황을 확인합니다.

**💬 쪽지** — 받은/보낸 쪽지 관리
<br>

### 예시 흐름: 새 학생 등록하고 수강 연결하기
```
원생 관리 → 학생 등록(이름·연락처·생년월일·주소) →강좌 관리에서 수업 확인 → 결제 목록에서 수강료 확인
```
### 예시 흐름: 비품 신청하기
```
자재 물품 신청 → 품목·수량·금액·사유·구매처 입력 → 제출 → 원장이 '결재 관리'에서 승인/반려
```

## 👩‍🏫 강사(TEACHER) 사용 가이드

강사는 본인이 담당하는 수업을 관리합니다. 로그인하면 **수업 시간표**로 들어갑니다.
<br>

### 이런 일을 할 수 있어요

**📅 시간표 — 수업 시간표**
본인의 수업 일정을 달력으로 확인합니다.

**✅ 원생 출결 — 원생 출결 관리**
수업별로 학생 출결(출석/결석/지각/조퇴)을 기록합니다.

**📁 수업 파일 — 수업 파일 관리**
수업 자료를 업로드하고 관리합니다.

**📝 성적 관리 — 원생 수업 테스트**
시험을 등록하고 학생별 점수를 입력·관리합니다.

**📋 강의계획서**
새 강좌의 강의계획서(대상·설명·커리큘럼 등)를 작성해 제출합니다.
제출한 계획서는 **승인 대기 → 승인 / 반려** 상태로 관리됩니다. (반려 시 사유 확인 가능)

**💬 쪽지** — 받은/보낸 쪽지 관리
<br>

### 예시 흐름: 오늘 수업 출결 체크하기
```
수업 시간표에서 오늘 수업 확인 → 원생 출결 관리 → 학생별 출석/결석/지각/조퇴 선택 → 저장
```
### 예시 흐름: 시험 성적 입력하기
```
성적 관리(원생 수업 테스트) → 시험 등록(시험명·날짜) → 학생별 점수 입력 → 저장
```

## ❓ 자주 묻는 질문

**Q. 로그인이 계속 풀려요.**
장시간 미사용 시 보안을 위해 자동 로그아웃될 수 있습니다. 다시 로그인해 주세요. (세션은 최대 7일 유지)

**Q. 다른 기기에서 로그인했더니 기존 기기가 로그아웃됐어요.**
보안상 **한 계정은 한 곳에서만** 로그인이 유지됩니다. 정상 동작입니다.

**Q. 메뉴가 제 동료와 달라요.**
역할(원장/관리자/강사)에 따라 보이는 메뉴가 다릅니다. 본인 업무에 맞는 화면만 표시됩니다.

**Q. 인증 메일이 안 와요.**
스팸함을 확인하고, 그래도 없으면 잠시 후 다시 시도하세요. 인증 링크는 15분간만 유효합니다.
